# Reliability audit — 2026-09-06

Historical starting point: `f7eba6c`, with `main` synchronized before editing.
This audit used offline fixtures, without host input or a real compositor.
Later developments are recorded in the [follow-up](audit-followup-2026-09.md).

## Reproduced and fixed failures

| Case | Before | Fix and regression |
| --- | --- | --- |
| Trickled IPC response | Each read renewed 3 s; test exceeded 4.5 s without finishing | Nonblocking socket and one monotonic connect/send/read budget; `tests/ipc.py` |
| Cancellation during silent IPC | SIGTERM did not end within 1 s; EINTR restarted waiting | Poll intervals of at most 50 ms with cancellation checks; `tests/ipc.py` |
| Extreme external timestamp | `minInt(i64)` overflowed subtraction and aborted without JSON in ReleaseSafe | Reject negative timestamps before arithmetic; geometry unit and integration tests |
| Viewer ignores SIGTERM | Parent and temporary rules remained pending beyond 3 s | Bounded grace, owned-child escalation and noncancelable 250 ms IPC cleanup; `tests/preview.py` |
| Helper ignores SIGTERM | Zig 0.16 `Child.kill` uses TERM + wait, insufficient for escalation | Shared TERM → KILL → reap handling; additional capture regression |

Shared child cleanup accepts only direct, unreaped `std.process.Child` processes.
It does not replace session-tree attribution. A kernel-blocked process can delay
reaping even after SIGKILL; this is not a real-time guarantee against kernel faults.

Inspection also found that token reads in `Runtime.guard` allocated in the action
arena. They were changed to use each check's temporary arena. No measured memory
saving was claimed for that inspection finding.

## Reproducible verification

```sh
zig build check -Doptimize=ReleaseSafe
zig build test
python3 tests/keyboard_unit.py
zig build pip -Doptimize=ReleaseSafe
```

New IPC, timestamp and viewer-close regressions first failed against the previous
behavior. A positive fragmented-response test was retained to avoid rejecting
valid communication. These tests do not establish visual equivalence or live
session performance.

Historical local result: 27 Zig unit tests and 107 Python tests (134 total) passed
`check`. The 27 Debug units, nine isolated keyboard units, and ReleaseSafe PiP build
also passed. `readelf` confirmed that the CLI did not link GTK. Zig formatting,
Python syntax and Bash syntax passed. Overlapping isolated keyboard tests are not
additional unique coverage.
